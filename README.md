# Titanic Survival Prediction

A data science project on the classic Kaggle Titanic dataset: exploratory data analysis and machine-learning models that predict whether a passenger survived.

## Contents

```
SDS_Project_final.ipynb   full analysis: EDA, feature engineering, and modeling
train.csv                 the Titanic training data
report.txt                written report
SDS_Project_PPT.pptx      project presentation
```

## What it covers

- Exploratory analysis of passenger features (class, age, sex, fare, and more)
- Feature engineering and handling of missing values
- Training and comparing classification models to predict survival

Open the notebook to reproduce the analysis end to end.
